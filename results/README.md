# results/

- `runs/<slug>/{config.yml,log.csv}`: the saved training configuration and per-epoch log of each of the 76 original runs
  (weights are not included). `runs_index.csv` maps each slug to the original folder name.
  Run names were assigned by hand after training; `config.yml` does not record which colour transform
  was used, only `input_channels`.
- `paper_reported.csv`: numbers transcribed from Tables 2, 3 and 4 of the ISBI 2024 paper
  (`table`, `group`, `model`, `metric`, `value`). The CWDB Dice for HSV+LAB is printed as "7791" in the paper
  and is read here as 0.7791.
- `runs_summary.csv`, `results_table.md`: generated by `scripts/make_results_table.py`.

Test-set numbers (paper Tables 3 and 4) have no saved output in this repository.
The validation numbers in Table 2 can be checked against `runs/` only where a saved log matches (see `results_table.md`).
